# 🩸 VAMPIRE RISE MD

A modular, database-free WhatsApp bot built with Node.js + TypeScript + Baileys.

**Developer:** KENYAN JAGUAR — +254115953912

## Features
- Registry-based command/menu system
- Categories configurable via JSON
- Provider architecture (AI, Music, Downloader, News, …)
- Private / Public modes
- Dev-only hidden commands
- Queued media & status automations
- No database — runtime settings in `config/runtime.json`

## Quick start
```bash
npm install
cp .env.example .env      # fill SESSION_ID
npm run dev
